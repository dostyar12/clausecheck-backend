Install ClauseCheck

Manual install for Chrome and Edge. Takes about a minute.

Download extension (.zip)
1

Download the ZIP using the green button above, then extract it to a folder anywhere on your computer (right-click → Extract).

2

Open your browser's extensions page: type chrome://extensions in Chrome, or edge://extensions in Edge.

3

Turn on Developer mode (toggle in the top-right corner).

4

Click "Load unpacked" and select the extracted folder (the one containing manifest.json).

5

ClauseCheck is installed! Pin it from the puzzle icon, then buy a license key below and enter it in the popup.
